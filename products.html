01 · LINEUP

The Fermi stack

Use one product on its own or run the full loop: guide during sampling, verify after, retrain on what failed.

Post-generation

Fermi VerifyCore

A trajectory verifier that reconstructs 3D scene geometry from generated frames and scores motion against conservation laws, flagging the exact frames where physics breaks.

  • Per-frame violation scores for momentum, energy, incompressibility and contact
  • SDF boundary checks catch interpenetration and fluid leaking through solids
  • Accept / reject / regenerate gate for production pipelines
Input
Any generated clip + optional prompt
Output
Physics score, violation map, frame report

During sampling

Fermi Guide

Inference-time guidance that nudges the denoising trajectory toward physically valid states, so fewer clips fail verification in the first place. No retraining of your base model.

  • Differentiable SDF and Navier–Stokes residuals as guidance terms
  • Drop-in sampler hook for diffusion and flow-matching DiTs
  • Tunable strength per law, from subtle correction to strict constraint
Input
Your sampler + latent at each step
Output
Physics-corrected latent update

Training data

Fermi Sim

Procedurally generated, simulator-labelled video with ground-truth geometry, velocity fields and contact events, for fine-tuning models on the cases they get wrong.

  • Rigid bodies, liquids and surface tension, vortex flow and wave media
  • Ground-truth depth, SDF, optical flow and velocity fields per frame
  • Targeted batches built from Fermi Verify failure reports
Input
Scenario spec or failure report
Output
Rendered clips + physical labels

  • Side-by-side model comparisons with per-law breakdowns
  • Regression alerts when a new checkpoint gets worse at physics
